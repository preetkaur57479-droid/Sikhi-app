# Meanings and audio: import rules

## Multiple meanings
Store each translation/teeka as a separate record. Do not merge different authors into one text. Show:
- translator/commentator and source
- language
- exact edition/section reference
- source link and attribution
- licence/permission status
- whether it has been human-reviewed

Offer a source selector and side-by-side comparison only after the source record is verified. Clearly distinguish literal translation, explanatory meaning (arth), and commentary (teeka).

## Audio
The audio index is intentionally empty. For each recording, obtain permission for streaming and separately for offline downloads. Store performer/raagi/jatha, source, track duration, attribution, rights, and linked Bani/verse IDs. A public video/audio URL is not automatically permission to copy or download it.

## Research notes
- ChetHari's public App Store description advertises audio search, queue, offline downloads and verse-linked audio. This project implements only the future search surface; it does not copy its audio catalogue or UI.
- SikhiToTheMax describes search over Gurmukhi, English and Punjabi and a range of scripture sources. Use it as a functional reference, not as permission to clone its database.
- Suraj Prakash meanings on the referenced Sikhitihas page are explicitly described as machine translations awaiting checking. Do not label them verified.
